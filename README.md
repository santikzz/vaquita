<h1 align="center">Vaquita</h1>

<p align="center">App para dividir gastos entre amigos, estilo Tricount. Mobile-first, instalable como PWA.</p>

## Qué hace

- **Grupos** persistentes con enlace de invitación; también grupos rápidos con invitados sin cuenta.
- **Eventos** dentro de cada grupo, eligiendo quiénes participan cada vez.
- **Gastos** divididos en partes iguales, por montos o por porciones.
- **Balances y saldar**: sugiere las transferencias mínimas y muestra el alias de MercadoPago para copiar.

## Stack

Laravel 12 · Inertia · React 19 · TypeScript · Tailwind v4 · shadcn/ui
